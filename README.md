## Название  
Автолавка "Арбузерс"

## Состав группы  
Лаврентьева Надежда (github: nlavrenteva), Миронова Софья (github: emsony), Пирогов Максим (github: maksimuspirogov-ship-it)

## Идея компании  
Мы запускаем сервис мобильной автолавки для малых деревень центральной России, где отсутствуют стационарные магазины. На основе данных о географии поселений, платежеспособности жителей и логистике мы строим оптимальные маршруты объезда и формируем продуктовую корзину, чтобы обеспечить жителей товарами первой необходимости с минимальными затратами.

## Разделение обязанностей  
- Лаврентьева Надежда – парсинг данных, анализ возраста, дохода, потребностей, использование API ВКонтакте или Telegram или Одноклассников, 3 мл-модели (1.бинарная классификация деревень, чтобы понять включать их или нет, 2.предсказание спроса в деревне, 3.кластеризация деревень для формирования маршрутов)
- Миронова Софья – составление списка деревень с координатами, построение оптимальных маршрутов объезда, формирование продуктовой корзины покупателей, использование Яндекс.Карты API или 2GIS API, составление дашборда с интерактивной картой маршрутов
- Пирогов Максим – анализ конкурентов и финансовая модель (существующие автолавки, поставщики, финансовые показатели, экономическая эффективность, юнит-экономика), использование Google Sheets API для финансовой модели, построение финансовых графиков с помощью matplotlib
